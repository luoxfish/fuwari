# 从 Markdown 开始写作

Markdown 用简单的纯文本语法表达结构。段落之间留一行空白；你可以使用 _斜体_、**粗体** 和 `行内代码` 来突出重点。

- 第一项
- 第二项
- 第三项

> 引用内容适合用来补充背景、摘录观点或强调一句值得回味的话。

## 列表与代码

有步骤的内容可使用有序列表：

1. 整理要表达的主题。
2. 写下清晰的标题和摘要。
3. 发布前检查链接与图片。

缩进四个空格即可创建代码块，也可以使用围栏代码块并指定语言：

```js
function greet(name) {
  console.log(`你好，${name}！`)
}
```

## 链接、表格与公式

可以链接到 [Astro 官网](https://astro.build/)，也可以链接到当前文章的 [上一节](#列表与代码)。脚注也很方便。[^1]

| 项目 | 说明 |
| --- | --- |
| 标题 | 用 `#` 到 `######` 创建层级标题。 |
| 链接 | 使用 `[文字](链接)`。 |
| 图片 | 使用 `![替代文字](图片链接)`。 |

行内公式例如 $E = mc^2$。独立公式可使用双美元符号：

$$
\int_a^b f(x)\,dx = F(b) - F(a)
$$

[^1]: 这是一个脚注示例。
